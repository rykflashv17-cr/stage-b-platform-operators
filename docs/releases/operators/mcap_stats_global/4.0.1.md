## 变更说明

- 相比 4.0.0，更新 SDK 至 `0.3.0.dev7` 并同步依赖锁。
- 本版本从归一化批次计算全局统计，输出包含统计缓存和归一化数据的 ZIP `statistics_context`；本次 Release 说明补齐不修改统计算法。

## 兼容性

- 保持 `normalized_batch_ref` 输入、`statistics_context` 输出和 `source`、`workers`、`recompute` 参数。
- 按整批调用，可接入 B01 4.0.1；调用方的来源配置须与归一化批次一致。
- 输出包含后续质检所需数据，不要求下游重新读取原始 MCAP。
