## 变更说明

- 相比 4.0.1，交付输出由 JSON 清单调整为 ZIP，包含通过项的原始 MCAP 和根目录 `delivery_manifest.json`。
- 校验质检判定、来源覆盖和汇总后，并发下载通过项原始文件，核对字节数与 SHA-256；无通过项时返回仅含空清单的 ZIP。

## 兼容性

- 输入 `batch_quality_result` 保持不变，可与 B01–B03 4.0.1 组合使用，不要求前三个节点同时升级。
- 输出由 `batch_delivery_result` 改为 `archive`。下游须更新输入绑定并按 ZIP 读取。
- 声明新增 `delivery.type: archive`、`delivery.format: zip`；SDK 使用锁定的 `0.3.0.dev9`，运行环境须授予读取通过项原始 MCAP 的权限。

## 已知限制

- 原始 MCAP 的对象键须位于平台为本次执行授权的存储位置；质检包的输入权限不能替代原文件读取权限。
- 本版本的本地与容器验收不代表平台交付页面或外部存储联调已经完成。
