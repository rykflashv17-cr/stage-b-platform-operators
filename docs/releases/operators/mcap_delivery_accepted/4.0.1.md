## 变更说明

- 相比 4.0.0，更新 SDK 至 `0.3.0.dev7` 并同步依赖锁。
- 本版本根据质检结果输出通过项的 JSON 交付清单 `batch_delivery_result`；本次补齐历史说明，不重建或修改旧版镜像。

## 兼容性

- 输入为 B03 4.0.1 的 `batch_quality_result`，按整批调用。
- 输出清单记录原始 MCAP 的引用与摘要，不包含原始 MCAP 文件；没有通过项时 `accepted` 为空数组。
- 需要包含原始文件的 ZIP 时，应显式升级 B04 5.0.0，并将下游绑定改为 `archive`；不能将两个版本的输出视为等价。
