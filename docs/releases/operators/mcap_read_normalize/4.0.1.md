## 变更说明

- 相比 4.0.0，更新 SDK 至 `0.3.0.dev7` 并同步依赖锁。
- 本版本从 `raw_files` 读取原始文件，输出归一化批次 ZIP `normalized_batch_ref`；本次 Release 说明补齐不修改业务处理行为。

## 兼容性

- 保持 `raw_files`、`normalized_batch_ref` 及 `source`、`workers` 的具名契约，按整批调用。
- 支持 `jindian_marvin`、`abc_130k` 来源。调用方须提交该来源要求的主文件和辅助文件。
- 使用本版本锁定的 SDK 与共享依赖；不能仅按相同字段名推定与任意下游版本兼容。
