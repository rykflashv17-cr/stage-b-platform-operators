## 变更说明

- 相比 4.0.0，更新 SDK 至 `0.3.0.dev7` 并同步依赖锁。
- 本版本读取统计包，输出包含判定、来源映射和汇总的 ZIP `batch_quality_result`，同时提交平台标准质检报告；本次 Release 说明补齐不修改质检算法。

## 兼容性

- 保持 `statistics_context` 输入、`batch_quality_result` 输出及 `source`、`workers` 参数，按整批调用。
- 可接入 B02 4.0.1；输出分别与 B04 4.0.1 清单交付、B04 5.0.0 归档交付形成兼容组合，两种交付结果不同。
- 平台标准质检报告由 SDK 单独提交，不作为新的具名业务输出。
