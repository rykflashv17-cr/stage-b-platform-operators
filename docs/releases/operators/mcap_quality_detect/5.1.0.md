# mcap_quality_detect 5.1.0（源码候选）

## 变更说明

新增 Marvin `joint_target_gap` 覆盖预检。质量帧到原 target 的最近距离严格大于 0.1 秒时正常拒绝整条 MCAP，保存原因和区间，并跳过 S1–S4。夹爪缺测证据保留，可与 target 缺口联合报告。

## 兼容性

单条输入输出业务名不变，依赖 `pretrain-cleaning-common 0.6.0`。真正的输入、解码或关键字段错误不得降级为正常拒绝；ABC 与原 S1–S4 数值规则不变。

## 已知限制

尚未发布；`uv.lock` 未重建，正式 SDK、wheel、锁定安装与 Docker 未验收。本轮源码验证见 [报告](../../../validation/single-file-target-coverage-20261118.json)，不沿用上一轮 31 项结果作为本轮证明。
